# 雷达运动时的保守占据清除

本修复只调整局部点云占据清除，不调整 EGO 速度、高度、膨胀尺寸或飞行控制。

## 算法

原实现只要扫描附近雷达起点移动超过 1/4 栅格分辨率，就停用整帧空闲射线。
新实现要求完整扫描区间的位姿覆盖，计算雷达起点包围盒，以盒中心作为名义射线起点。
包围盒额外包含位姿插值误差、旋转安装偏移的曲线误差和基础误差余量。

对于名义射线上参数 u 对应的位置，可能的真实射线位置误差为
`(1-u) * origin_half_extent`。只有该位置的整个误差盒都在旧栅格内部，且满足
盲区、终点保护和连续空闲确认条件，才降低旧占据概率。这个检查使用真实测量
终点，不能使用地图边界或最大射程截断产生的虚拟终点，否则会低估误差。

当前命中立即占据并清空空闲确认；重复点不算多个确认。盲区、遮挡、无回波
和过期数据不作为删除依据；不增加按时间自动删除。

## 输入假设和降级

当前 MID360 配置为 10 Hz，FAST-LIO 点云与 /Odometry 的时间戳均为扫描结束时间。
`cloud_scan_duration` 必须覆盖整帧扫描时长，修改雷达输出频率或分帧配置时必须同步检查。
姿态插值采用最短弧，扫描间平移/角加速度需在配置的误差界内。
这是一种基于有界运动误差的保守模型，不替代每束激光的真实采样时间和起点。

位姿区间不完整、位姿间隔过大、扫描内转动或起点变化过大时，保留新命中，暂停清除。
运动时部分擦边栅格仍可能无法清除；停稳复核仍是必要的后备手段。

参数位于 EGO 节点的 `grid_map/` 下：

| 参数 | 默认值 | 含义 |
|---|---:|---|
| cloud_scan_duration | 0.10 s | 扫描覆盖时长 |
| cloud_clear_max_origin_span | 0.15 m | 扫描起点盒对角跨度上限 |
| cloud_clear_max_pose_gap | 0.15 s | 原始位姿采样最大间隔 |
| cloud_clear_acceleration_bound | 6.0 m/s² | 位姿插值的平移加速度界 |
| cloud_clear_angular_acceleration_bound | 20 rad/s² | 姿态插值的角加速度界 |
| cloud_clear_origin_margin | 0.0025 m | 起点基础余量 |
| cloud_free_interior_margin | 分辨率的 5% | 栅格内部边缘保护余量 |

旧参数 `cloud_clear_motion_limit` 已弃用；若配置存在，节点启动会输出提示。
不要为了增加清除量而降低运动误差界，或随意扩大起点跨度与位姿间隔上限。

## 诊断

融合状态新增 `clear_reason`、`origin_uncertainty`、`uncertain_cells`。
`uncertain_cells` 是射线候选的拒绝次数，不是唯一栅格数量。
等待位姿时的状态包含上一次地图统计；比较清除量必须选取 `update_ms > 0`
的成功更新，并按 `stamp` 去重。

## 验证和启用

验证包括原有保护回归、快速运动误差盒、盲区扩大、当前命中优先、错误误差盒、
地图边界/射程截断、ROS 位姿覆盖缺失，以及独立 ROS master 的实测录包对照。
离线回放保留原始时间戳并使用仿真时钟，以便放慢墙上时间而不改变被测运动速度。

编译和测试在独立目录完成。替换程序文件使用临时文件加原子改名，保留旧进程
已经映射的文件；当前运行节点仍执行旧版逻辑，需之后重启比赛 EGO 链路才启用。
本修复不保证消除规划爬升或所有假堵塞；高度偏好和规划失败制动属于后续工作。

## 2026-10-14 验证记录

31 项占据融合单元测试通过；25 项独立 ROS 检查通过，包含地图/位姿异常、
运动清除和实际 EGO 绕障闭环。安装后的程序另通过 20 项地图接入检查。
固定高度手持录包共 535 帧点云，回放使用独立 localhost:11432 master，不连接飞控。
以位姿差分速度大于 0.2 m/s 选取运动片段：

| 指标 | 原版 | 修复版 |
|---|---:|---:|
| 融合更新 | 534 | 535 |
| 运动片段更新 | 59 | 59 |
| 运动时允许清除的更新 | 0 | 59 |
| 运动时清除的旧占据 | 0 | 1,171 |
| 融合耗时中位数 | 55.14 ms | 55.36 ms |
| 融合耗时 P95 | 73.85 ms | 69.24 ms |

这里的耗时属于放慢墙上时间的离线回放，不代表实际飞行延迟。
被清除数量证明运动清除功能有效，不单独证明每个历史占据都是假障碍，
也不证明绕柱爬升已经消除。实飞启用后仍需要停桨固定高度复核。
